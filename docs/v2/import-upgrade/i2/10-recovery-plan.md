# I2 — שחזור

הקובץ `10-rollback.manual.sql` אינו שחזור ייצור. הוא לא רץ כחלק מההחלה.

## סכמה ריקה

הטבלאות החדשות קיימות ובכולן אפס שורות. לא נשמרו מפרטי צמיג, משלוחים, הקצאות או קליטות חדשות.

באותה שיחה, לפני הקובץ:

```sql
SET i2.recovery = 'empty-schema';
```

הקובץ סופר את הטבלאות החדשות. רק אם כולן ריקות הוא מסיר את אובייקטי I2 ואת העמודות שנוספו ל־`import_orders` ול־`import_payments`. בלי ההגדרה הוא נעצר לפני המחיקה.

## סכמה עם רשומות

שורה אחת בטבלה חדשה עוצרת את הקובץ. שום טבלה לא נמחקת. הרשומות נשארות. תיקון המשך נעשה בקובץ חדש, או שחזור מגיבוי שנלקח לפני ההחלה.

## שחזור ייצור

דורש גיבוי שנלקח לפני ההחלה, ואישור מפורש לשחזר ממנו. אין להריץ את קובץ המחיקה על ייצור כדי "לנקות" רשומות. הזמנות יבוא, מוצרים, קליטות ישנות והתאמות עלות ישנות לא נמצאים ברשימת המחיקה גם במצב הריק.
